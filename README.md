# 2026 数学建模国赛 LaTeX 模板

仓库根目录已经放置可直接编译的全国大学生数学建模竞赛论文模板。

## 在 Overleaf 中使用

1. 在 Overleaf 中选择 **New Project → Import from GitHub**，并选择本仓库。
2. 主文档使用根目录下的 `main.tex`。
3. 编译器使用 **XeLaTeX**；仓库中的 `.latexmkrc` 已预先配置。
4. 在 `main.tex` 开头修改论文题目、题号、报名号、学校、队员和日期，然后开始写作。

模板所需的 `cumcmthesis.cls`、图片和跨平台字体配置均已包含在仓库中，不依赖 Windows 本机字体。

> 提交前请对照当年全国大学生数学建模竞赛的官方论文格式要求检查模板内容。
